# Montevar — Casa de lujo en la montaña

Sitio inmobiliario de lujo (proyecto conceptual): hero con letras gigantes detrás de la casa, entorno con panorámica arrastrable, recorrido interior con puntos interactivos, plano clickeable y galería en pantalla completa.

HTML + CSS + JS puro, imágenes WebP optimizadas. Imágenes generadas con IA.

## Recorrido 3D
`casa3d.js` (three.js r170, se carga solo al tocar "Abrir recorrido 3D"): la casa del hero modelada en 3D, pisos rústicos de madera ancha y travertino en baño/spa, sombras suaves, tone mapping ACES, iluminación HDRI y piscina con reflejos reales. Botón de calidad Alta / Fluida para celulares.

Créditos (CC0): texturas e HDRI de [Poly Haven](https://polyhaven.com) (wood_planks, castle_wall_varriation, japanese_stone_wall, dark_wooden_planks, wood_floor_worn, box_profile_metal_sheet, brown_leather, poly_wool_herringbone, rocks_ground_02, leafy_grass, evening_road_01) y [ambientCG](https://ambientcg.com) (Travertine009). three.js (MIT).
